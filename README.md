# Smart Mart

A modular C console application for managing a small smart-mart system.

## Features

- Product management
- Customer management
- Membership management
- Sales tracking
- Text-file-based data storage

## Project files

- `main.c` — program entry point
- `customer.c` — customer-related features
- `membership.c` — membership-related features
- `products.c` — product-related features
- `sales.c` — sales-related features
- `manager.c` — management features
- `data.c` — data-handling features
- `app.h` — shared declarations
- `members.txt`, `products.txt`, `sales.txt` — project data files
- `Smart Mart.cbp` — Code::Blocks project file

## How to run

1. Install Code::Blocks with a C compiler.
2. Open `Smart Mart.cbp` in Code::Blocks.
3. Build and run the project.
4. Keep `members.txt`, `products.txt`, and `sales.txt` in the project folder. Do not rename them.
